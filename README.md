# Employee Performance Dashboard

## Features

- Employee CRUD
- Task Management
- Interaction Tracking
- KPI Dashboard
- CSV Import
- Audit Logs
- Employee Ratings
- SQLite Database
- Streamlit UI

---

## Installation

### 1. Install dependencies

```bash
pip install -r requirements.txt
```

### 2. Seed sample data

```bash
python seed.py
```

### 3. Run app

```bash
streamlit run app.py
```
